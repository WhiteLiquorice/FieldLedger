# Sample service record

`FieldLedger-Sample-Service-Record.pdf` is a fictional hood-cleaning visit generated with the application's PDF renderer through `scripts/sample-report.ts`. Its company, customer, work, observations and photographs are illustrative. It is not evidence of an actual service visit.

The image `illustrative-hood-cleaning.png` was generated with the built-in image generation tool. Prompt: a realistic fictional two-panel comparison of the same commercial kitchen hood, with moderate grease before and a clean hood after, ordinary lighting, no people, logos or certificates, white caption bands identifying before/after illustrative examples, and a prominent simulated-images/not-a-record-of-work-performed label. No reference images were used.

The PDF was rendered to PNG and both pages visually inspected. The website's public sample is a copy of this PDF. Regenerate the PDF with the script when changing the sample; update the public copy and rerun the release gate.
